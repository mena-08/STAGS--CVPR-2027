\section{Discussion and Limitations}
\label{sec:discussion}

STAGS shows that a single Gaussian mixture can drive a complete STA pipeline, from pose search through polishing; on EMPIAR-10164 it matches the half-map FSC crossing of RELION's polished map in a fraction of the logged processing time.

\paragraph{Limitations.}
STAGS's own half maps stay above FSC~0.143 up to Nyquist, so we report agreement with RELION's half maps rather than gold-standard resolution, and RELION's map still agrees better with the atomic model (FSC~0.5 at 3.86 vs.\ 4.04\,\AA).
